# Diego Hartwig — Portfolio

Site profissional de **Diego Hartwig**: apresentação de trajetória, áreas
de atuação e publicações técnicas nas interseções entre **Engenharia de
Software, Engenharia de Dados e Inteligência Artificial Aplicada**.

Disponível em [diegohartwig.com.br](https://diegohartwig.com.br/).

## Tecnologias

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Fontes self-hosted via `@fontsource/inter` e `@fontsource/newsreader`

Single Page Application com pré-renderização estática no build, para que
o conteúdo da página já esteja presente no HTML entregue ao navegador.

## Deploy

GitHub Pages, via GitHub Actions.
